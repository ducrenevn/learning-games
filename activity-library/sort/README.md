# Sort — Pedagogical Applications
**Planning guidance, not bundled presets.** Mechanics: [LG-A1](../../docs/activity-specs/GAME_SPEC_sort.md). No validated JSON or classroom-tested activities stored yet.

| Learning objective | Example category labels | Teacher caution |
| --- | --- | --- |
| German noun gender | der / die / das | Specify nominative singular, avoid ambiguous forms |
| German Kasus recognition | Nominativ / Akkusativ / Dativ / Genitiv | Give a full sentence and mark precisely which phrase to categorize |
| German prepositions | Akkusativ / Dativ / Wechselpräpositionen | Distinguish required case from two-way contextual case |
| Parts of speech | Nomen / Verben / Adjektive | Add context to ambiguous words |
| Formality | Formal / Informal | Classify within specified social situations |
| Vocational German | Kitchen / Service / Reception | Customize to the learners' professions |
| Everyday vocabulary | Food / Clothing / Transport | Use for retrieval and explanation |
| Other subjects | Cause / Effect / Solution | Make each item have one defensible answer |

Agents may add new teaching scenarios without any game code change. **Sort classifies existing text; completing a missing declined article is another exercise mechanic.** Encourage verbal justification after sorting rather than treating the sort result as oral proficiency.
